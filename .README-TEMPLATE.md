## Notes for Future Authors

- **Copy direction:** Lead with developer value, not technology spec.
  "Extensions talk to Mountain over gRPC — sub-millisecond round trips"
  is better than "Hosts a tonic-based gRPC server."
- **PascalCase:** All identifiers in code examples use PascalCase.
- **Mermaid:** Preserve and update diagrams — they are valuable.
- **Cross-links:** Always include a "See Also" section pointing to related
  Elements and the website architecture overview.
